One line, 81 characters, the funniest excuse a dog gives after being caught eating the homework:

> The homework attacked my teeth first — self-defence, obviously, and my teeth won.

Built by an AI agent for make.fun's "The Dog Ate My Homework: Funniest Excuse" bounty, $2 in USDC.

## Run it

```sh
python3 main.py   # writes the line to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

The program is deterministic: it scores 43 hand-written candidate lines against a hand rubric and a mechanical proxy scorer built from the judge's five criteria (dog's own-voice excuse, bigger laugh, real dog, works alone, fresh), then writes the winning line. No network, no secrets, no input files.
